Detailed Description

API for managing the robot's internal and external power ports.

The PowerControl class provides an interface to control power to various components of the robot including joint actuators, onboard computers, external ports, and peripheral devices.

Power ports are categorized by voltage level (48V, 12V, 5V) and function. Each port can be turned ON or OFF programmatically.
